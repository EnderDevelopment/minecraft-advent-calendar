# Adventskalender

Der Adventskalender ist ein Minecraft-Plugin, das einen interaktiven Adventskalender für die Spieler bereitstellt. Es bietet eine GUI, in der Spieler Geschenke für jeden Tag des Adventskalenders abholen können. Das Plugin ist ressourcenbewusst entwickelt und kann einfach in Minecraft-Server integriert werden. Es enthält eine ausführliche Konfiguration, um die Geschenke anzupassen, und eine Berechtigung für Administratoren, um das Plugin vor dem 21. Dezember zu testen.

## Install

1. Lade die neueste Version des Plugins von der [GitHub-Seite](https://github.com/EnderDevelopment/Calender) herunter.
2. Kopiere die heruntergeladene JAR-Datei in den `plugins`-Ordner deines Minecraft-Servers.
3. Starte oder starte den Server neu, um das Plugin zu aktivieren.

## Use

1. Öffne den Adventskalender mit dem Befehl `/calender`.
2. Klicke auf die Truhen, um die Geschenke für den jeweiligen Tag abzurufen.
3. Geschenke, die bereits abgeholt wurden, werden durch Kohle ersetzt.
4. Klicke auf die Barriere unten rechts, um das GUI zu schließen.
